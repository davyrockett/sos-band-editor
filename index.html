            Sending changes to the band app

            Your access key lets this editor save to GitHub, where the band app reads from. Paste it once on each device you edit on.

            Where do I get the key?
            1. On github.com (signed in as davyrockett), go to Settings → Developer settings → Personal access tokens → Fine-grained tokens.
            2. Open Z4 Log sync, then Edit.
            3. Under Repository access, add sos-band-data, then Update.

            Or make a separate key (to give a bandmate): Generate new token, name it “SOS Band”, choose Only select repositories → sos-band-data, and set Repository permissions → Contents to Read and write.
