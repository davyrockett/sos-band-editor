# SOS Band Editor

David's editor for the SOS Band's setlist, chord charts, stage plot, gear list and mixer routing.
Live: https://www.davyrockett.com/sos-band-editor/ (just for David).
The band sees everything in the view-only **SOS Band** app: https://www.davyrockett.com/sos-band/

## How it works
- Edit anything: drag songs to reorder, add songs to the set, set lead singers and keys, upload charts,
  drag people around the stage plot (tap someone to edit them), edit gear and mixer channels, add band members.
- Your changes reach the band app within a minute or two, once your access key is in Settings
  (without it, a red banner says changes are only on this device).
- Tap the gig name to switch gigs, start a new one (**New gig (copy of this)**), or pick
  **★ Make the band app open on this gig**. Band members can switch gigs too; ★ is just where their app opens.
- **Perform** (Setlist): the set's charts full screen for playing. Tap the right side for the next page, the left side
  for the page before (it carries on into the next song); tap the middle for Close, a song list and the metronome button,
  which pops up a small metronome in the corner already set to the song's tempo. The screen stays on. Page-turner pedals work.
- **Metronome** (the metronome icon beside the gear): type each song's tempo in the list under it (or in Edit song). Tap a song (or use ‹ ›) to load
  its tempo, then **Start**. **Silent (flash)** only flashes the box, brighter on beat 1. Also: − / +, slider,
  Tap tempo, 2 / 3 / 4 / 6 beats. The screen stays on while it runs; it stops if you leave the app. Tap the icon again to go back.
  Band members see the tempos and can use it too. Edit song also has a **Tap tempo** button beside the tempo box.
- **New charts:** put the PDF in Dropbox → Resounding Joy → SOS Band → SOS Chord Charts, then double-click
  **Sync SOS Charts.command**. The song appears in both apps' song lists a minute or two later; tap **+ Set**
  to add it to a gig. (Replacing a PDF there and syncing updates that chart.) You can also add a song with its PDF
  straight from the app with **+ New song**.
